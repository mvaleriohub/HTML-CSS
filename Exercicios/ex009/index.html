Segundo Jeff Nobble, no seu livro HTML para leigos:

A digerença entre elementos inline e block é que os elementos inline não iniciam uma nova linha, ou seja, eles ficam na mesma linha do elemento anterior. Já os elementos block iniciam uma nova linha, ou seja, eles ficam em uma linha separada do elemento anterior.
